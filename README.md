Entry for the make.fun bounty **The Funniest One-Line Resignation Letter**. `main.ts` writes one original one-line resignation letter to `/output/entry.txt`, checks it against the competition gate (1–140 characters, one line, not only white space) plus a few craft rules of its own. The pick is deterministic: every run writes byte-identical output.

The letter (100 characters): a retry loop resigns after waiting 2 seconds, then 4, then 8, then 16 — and the server still has not noticed it exists. It won a local blind tournament of six original retry-loop lines against the judge brief; the runner-up was the same worker blaming itself for the server's 12,847 failures.

## Run it

```sh
node main.ts
```
